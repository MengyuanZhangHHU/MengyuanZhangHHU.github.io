张萌媛个人学术主页 V3 / GitHub Pages 部署说明

将本 ZIP 内 index.html、style.css、site.js、robots.txt、.nojekyll 解压到 GitHub Pages 仓库根目录。
Settings → Pages → Build and deployment → Deploy from a branch → main / (root)。
访问密码仍为此前确认的 HHUZMY。
仅部署本包内文件；不要上传“可编辑源码”ZIP。
网站采用 AES-256-GCM 客户端内容加密。密码保护并不等于服务器身份验证。
注意：GitHub Pages 的网页必须通过 https:// 域名访问，直接在本地 file:// 双击打开可能无法使用 Web Crypto。
